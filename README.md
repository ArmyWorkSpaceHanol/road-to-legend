# ROAD TO LEGEND

혼자 즐기는 야구 선수 인생 웹게임. **시즌 목표·육성 계획 선택 → 전반기 진행 → 주요 사건 선택 → 시즌 결산·시상식 확인 → 진로·계약 선택**을 반복하며 커리어를 쌓습니다.

React + TypeScript + Vite로 구현했습니다. 게스트 버전은 브라우저만으로 실행하며, 서비스 버전은 ChatGPT 로그인과 Cloudflare D1의 계정별 클라우드 저장을 제공합니다. 한국어 폰트도 함께 제공하므로 외부 폰트 서비스에 의존하지 않습니다.

## 로그인 서비스

서비스 주소: <https://road-to-legend-clubhouse.smp6340.chatgpt.site>

Sites에서 관리하는 ChatGPT 인증을 사용합니다. 별도의 비밀번호나 가짜 로그인은 없습니다. 현재 배포의 접근 권한은 소유자 전용 비공개입니다. 일반 방문자에게 공개하려면 Sites의 접근 정책을 별도로 변경해야 합니다.

- 로그인 사용자 ID를 서버의 소유자 키로 사용합니다. 클라이언트가 전달한 사용자 ID는 신뢰하지 않습니다.
- 현재 커리어, 슬롯 3개, 자동 백업 2개를 계정별로 저장합니다. 기기 캐시도 계정마다 분리합니다.
- 오프라인 변경은 기기에 보존하고 연결 복구 시 재시도합니다. 클라우드 저장 전에는 로그아웃을 막고, 탭을 닫을 때 브라우저 확인을 표시합니다.
- 여러 기기의 수정이 충돌하면 사용자가 이어갈 기록을 선택합니다. 클라우드 기록으로 바꾸기 전에는 기기 기록을 파일로 내보냅니다.
- 계정 패널에서 전체 기록 내보내기, 기존 단일 커리어 파일 또는 계정 백업 가져오기, 이 브라우저의 게스트 기록 가져오기, 게임 데이터 삭제를 제공합니다. 다른 주소의 GitHub Pages 기록은 파일로 옮겨야 합니다.
- 서버는 세이브 스키마·요청 크기·동일 출처 쓰기를 검증하고, 저장 버전을 비교해 이전 기기의 덮어쓰기를 거부합니다. 저장 내용은 압축해 D1에 보관합니다. 압축된 레코드가 D1 한도를 넘으면 오류를 표시하고 기기 기록을 유지합니다.

서비스용 빌드:

```sh
npm run db:generate     # db/schema.ts 변경 시에만 실행; 생성된 SQL과 메타데이터 커밋
npm run build:service   # dist/server/index.js + 임베드된 정적 리소스
```

`.openai/hosting.json`의 프로젝트 ID와 DB 바인딩을 보존하고, Sites 배포 시 Drizzle 마이그레이션을 적용합니다. `oai-authenticated-user-*` 헤더를 검증해 주는 관리형 게이트웨이 뒤에서만 서버를 배포해야 합니다. 일반 HTTP 서버에 그대로 공개해서 이 헤더를 신뢰하면 안 됩니다. 인증 경로(`/signin-with-chatgpt`, `/signout-with-chatgpt`, `/callback`)는 호스팅 플랫폼이 처리합니다.

3D 구장은 추가 WebGL 의존성 없이 CSS perspective와 입체 레이어로 렌더링합니다. 모바일에서는 크기와 상세도를 줄이고, 운영체제의 동작 줄이기 설정을 적용합니다. 게임 화면은 필요할 때 불러옵니다.

## 실행

Node.js 24 이상을 사용합니다. 검증한 버전은 `.nvmrc`의 24.22.1입니다.

```sh
cd /workspace/road-to-legend
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

일반 PC에서는 원하는 작업 디렉터리와 쓰기 가능한 npm 캐시를 사용하면 됩니다. 개발 서버는 5173번 포트에서 실행됩니다.

```sh
npm test                       # 시뮬레이션·기록·계약·저장 데이터 테스트
npm run build                  # 타입 검사 및 프로덕션 빌드
npm run test:ux                # 실행 중인 서버에서 저장 슬롯·화면 복원·키보드 메뉴 검증
npm run test:creation          # 전체 포지션 생성·고등학교 직접 입력·저장/복원 검증
npm run test:service           # 시작 화면·계정 UI·오프라인·충돌·삭제 흐름 검증
npm run preview -- --port 4173  # 빌드 결과 실행
```

브라우저 통합 검증은 개발 서버를 실행한 상태에서 별도 터미널로 진행합니다.

```sh
CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
```

Chromium이 없는 PC에서는 `npx playwright install chromium`을 실행한 뒤 `npm run test:browser`를 사용합니다. `BASE_URL`로 검사할 서버를 지정할 수 있습니다. 캡처는 Git에서 제외된 `test-results/`에 저장합니다.

## GitHub Pages에서 플레이

`main` 푸시 시 GitHub Actions가 테스트·빌드를 실행하고 GitHub Pages로 배포합니다. 첫 배포 전에는 저장소의 [Settings → Pages](https://github.com/ArmyWorkSpaceHanol/road-to-legend/settings/pages)에서 **Build and deployment → Source → GitHub Actions**를 선택해야 합니다. API 키나 별도 서버는 필요하지 않습니다.

설정을 완료한 뒤 [Actions](https://github.com/ArmyWorkSpaceHanol/road-to-legend/actions/workflows/deploy.yml)에서 **Validate and deploy to GitHub Pages** 워크플로를 실행하거나 실패한 실행을 다시 실행하세요. 배포가 성공하면 다음 주소에서 플레이할 수 있습니다.

<https://armyworkspacehanol.github.io/road-to-legend/>

Vite 빌드의 리소스 경로는 상대 경로이므로 저장소 하위 경로에서도 카드 화면과 폰트가 정상 로드됩니다. 개발 환경과 배포 사이트의 저장 데이터는 서로 별개이므로 기존 커리어를 옮기려면 백업 파일을 불러오세요.

## 플레이

- 처음 접속하거나 **새 커리어**를 누르면 이름, 야수·투수, 포지션, 출발할 고등학교와 선호 프로 구단을 설정합니다. 야수는 포수·1루수·2루수·3루수·유격수·좌익수·중견수·우익수·지명타자, 투수는 선발·중간계투·롱릴리프·셋업맨·마무리를 선택할 수 있습니다. 새 커리어는 16세 고교 1학년부터 시작하며 선호 구단이 프로 입단을 보장하지 않습니다.
- **고등학교는 직접 입력**할 수 있으며, 추천 학교도 선택할 수 있습니다. 앞뒤 공백을 제외한 1~40자의 이름을 받습니다. 입력한 학교는 실제 고교 소속·순위표·리더보드·연도별 기록에 반영되고, 졸업 후에도 출신 고교 정보와 과거 기록에 남습니다. 선발은 선발 출장, 불펜은 구원 출장과 역할에 맞는 이닝·홀드·세이브를 생성합니다. 구단별 대표 선수 표본에도 모든 포지션을 배치하므로 새 포지션의 골든글러브도 경쟁하여 선정합니다.
- 기본 설정 다음에는 뒷면으로 놓인 **시작 카드 3장**이 나옵니다. 한 장씩 뒤집어 모두 확인한 뒤, 마음에 드는 카드 하나를 선택하고 시작합니다. 카드를 선택하기 전까지 기존 커리어는 교체되지 않습니다.
- 타자는 **거포형·수비형·주루형·균등형**, 투수는 **강속구형·제구형·변화구형·균등형** 중 서로 다른 컨셉 3장이 무작위로 나옵니다. 세부 능력치는 컨셉에 맞는 기준값에서 각각 ±5로 변동하며, 표시된 값이 그대로 시작 능력치가 됩니다. 기본 설정으로 돌아갔다 와도 같은 선수 유형의 카드와 공개 상태가 유지됩니다.
- 선택한 컨셉과 최초 능력치는 저장·복원되고 이후 육성은 자유롭습니다. 이전 버전의 저장 파일도 그대로 사용할 수 있습니다.
- **시즌 목표**는 성장·개인 성적·출장 중 하나를 선택합니다. 단계·포지션에 맞는 목표가 제시되고 시즌 결산에 실제 달성 수치가 남습니다. 프로 개인 성적 목표는 1·2군 합산이며, 1군 등록 목표는 실제 등록일만 계산합니다.
- **선수 육성**에서 육성 방향 1개, 훈련 지원 1개를 선택합니다. 시즌을 진행할 때 성장·비용이 한 번 적용됩니다.
- **시즌 진행**을 누르면 전반기 기록과 주요 사건이 표시됩니다. 폼 교정·추가 훈련·회복 중 사건에 맞는 방향을 선택하면 후반기에 능력치·감독 신뢰·피로·출장 기회가 반영됩니다. 선택 화면을 닫거나 새로고침해도 **시즌 이어하기**로 계속할 수 있습니다. **주요 사건 자동 선택**을 켜면 기본기·회복을 우선해 한 번에 시즌을 마칩니다. 정규시즌 일정은 다음과 같습니다: 고교 30경기, 대학 42경기, 독립리그 60경기, KBO 144경기, NPB 143경기, MLB 162경기입니다. 프로의 2군 일정은 120경기이며, 실제 소속 구간과 출장 기회만 기록됩니다.
- 시즌 종료 후 **시즌 결산 → 기록 확인 → 시상식 → 진로·계약**을 상단 단계와 하단 이전·다음 버튼으로 이동합니다. 결산에서 목표·주요 선택·성장·감독 피드백을 확인하고, 다음 시즌은 육성 화면에서 준비합니다. 순위표·연도별 기록은 10개씩, 감독 평가는 6개씩 페이지를 나눠 볼 수 있습니다. 정렬·필터를 바꾸면 첫 페이지로 돌아갑니다.
- **나의 기록실**에서 원시 기록과 비율 기록, 연도별·통산 성적을 확인합니다. 통산 비율은 합산한 타수·안타 등으로 다시 계산합니다.
- **나의 기록실 → 커리어 도전**에서 타자의 경기·안타·홈런·타점·도루·볼넷, 투수의 등판·승·탈삼진·이닝·세이브·홀드 마일스톤을 확인합니다. 다음 목표까지 남은 기록과 각 단계의 최초 달성 시즌을 표시하며, 달성 이력은 10개씩 볼 수 있습니다. 아마추어·프로 1군·프로 2군과 리그별 기록을 구분하고, 전체 프로 리그를 선택하면 KBO·NPB·MLB의 해당 군 기록을 합산합니다. 시즌 중간 기록은 완료 후 반영합니다.
- **나의 기록실 → 성장 비교**에서 선택한 기록 구분·리그의 최근 다섯 시즌을 그래프와 표로 비교합니다. 종합 능력치·WAR·타격/투구 성적을 전환하고, 직전 해당 범위 시즌과의 성적·능력치 차이 및 출장·부상 정보를 확인할 수 있습니다. 2군은 WAR를 제공하지 않으며, 출장 기록이 없는 비율 지표는 `—`로 표시합니다.
- 화면·기록 구분·시즌·리그·성장 지표·리더보드 정렬·규정 출장 필터·진로 화면 구분을 주소에 보관합니다. 브라우저 뒤로가기·앞으로가기와 새로고침으로 보던 화면을 이어갈 수 있습니다. 주소에는 선수 저장 데이터가 포함되지 않으므로 다른 브라우저에서 같은 커리어를 보려면 JSON 백업도 옮겨야 합니다.
- 같은 화면의 **나의 최고 시즌**에서 개인 최고 기록을 확인합니다. 타율·OPS는 팀 정규시즌 경기 수 × 3.1 이상의 타석, ERA·WHIP는 팀 경기 수 이상의 이닝을 소화한 시즌만 비교합니다. 2군 기준은 120경기이며, 동률이면 먼저 달성한 시즌을 표시합니다. 저장 이력에서 계산하므로 기존 백업도 별도 변환 없이 사용할 수 있습니다.
- **리그 순위**는 구단 순위와 가상 대표 선수들의 개인 순위를 제공합니다. 열 이름으로 정렬하고 규정 출장 선수만 볼 수 있습니다.
- **시상식**에서 시즌 MVP, 타격왕, 홈런왕, 타점왕, 도루왕, 최우수 투수, ERA·삼진 타이틀, 해당 포지션 골든글러브를 확인합니다. 프로 신인상은 시즌 시작 전 1군 누적 130타석·50이닝 미만이며 해당 시즌 WAR 1.5 이상인 경우에 적용합니다. 아마추어 시상식은 프로와 별도입니다.
- 시즌 종료 후 **진로·계약**에서 학년에 맞는 진로 또는 프로 계약을 선택합니다. **다음 시즌 준비**를 누르면 선택한 계약이 적용되며, 기본 선택은 재계약입니다.
- 진로 화면의 **계약과 진로 / 대표팀·상무 / 감독 평가** 버튼으로 필요한 내용을 선택합니다. 연봉 재협상과 FA·포스팅 자격은 계약 화면에서 펼쳐볼 수 있습니다. 모바일 메뉴는 Esc로 닫고 Tab으로 메뉴 안을 이동할 수 있으며, 닫으면 메뉴 버튼으로 포커스가 돌아갑니다.
- 16세 고교 1학년부터 학년·나이가 함께 증가하며, 40세 시즌 후 은퇴합니다. 커리어 기록과 트로피는 계속 열람할 수 있습니다.

### 육성과 경기 결과

시즌 중간 사건은 폼 교정·출장 기회·휴식에 더해 **포지션 라이벌 경쟁·슬럼프 극복·부상 복귀**를 제공합니다. 부상 기간·피로·최근 완료한 시즌의 경기력을 반영하며, 두 선택의 능력치·감독 신뢰·피로·휴식 효과는 선택 전에 표시합니다. 실제 선발 추첨을 추가로 제공하는 사건은 아니며, 전반기 기록은 선택으로 바뀌지 않습니다. 이전 버전에서 선택을 기다리던 사건도 저장된 종류 그대로 이어집니다.

타자는 컨택·파워·스피드·수비·선구안·멘탈을, 투수는 제구·구위·체력·변화구·위기 관리·멘탈을 육성합니다. 능력치는 절대 상한 99 이내에서 선수별로 정해진 성장 잠재력(76~94)에 따라 성장합니다. 나이·집중 훈련·지원 방식·잠재력까지의 거리가 성장량에 반영됩니다. 32세부터 노화가 적용됩니다. 회복 훈련·컨디셔닝 지원은 부상 확률을 줄이고, 부상은 실제 출장 수를 줄입니다.

컨택·선구안은 출루와 삼진, 파워는 장타, 스피드는 주루, 수비는 기여도, 멘탈은 득점 생산에 영향을 줍니다. 투수의 제구·구위·변화구는 상대 타석 결과에, 체력은 소화 이닝에, 위기 관리·멘탈은 실점에 영향을 줍니다. 동일한 저장 상태는 동일한 결과를 내는 시드 기반 시뮬레이션입니다.

### 진로와 프로 등록

| 시점               | 선택과 결과                                                         |
| ------------------ | ------------------------------------------------------------------- |
| 고교 1~2학년 종료  | 다음 학년으로 진급                                                  |
| 고교 3학년 종료    | 드래프트 지원 또는 대학 진학. 미지명자는 선택한 대학 1학년으로 진학 |
| 대학 1학년 종료    | 2학년 진급                                                          |
| 대학 2학년 종료    | 얼리 드래프트 또는 잔류. 얼리 미지명자는 3학년으로 복귀             |
| 대학 3학년 종료    | 4학년 진급                                                          |
| 대학 4학년 종료    | 졸업 드래프트. 미지명자는 독립리그에서 재도전                       |
| 독립리그 시즌 종료 | 테스트 입단 지원. 불합격해도 다음 시즌 재도전 가능                  |
| 지명·테스트 합격   | 계약금과 첫 연봉을 적용하고 다음 시즌 프로 2군에서 시작             |

드래프트 평가에는 포지션 기량, 마지막 시즌의 실제 경기력, 출장 노출과 멘탈을 사용합니다. 구단별 포지션 경쟁도와 수요도 지명 구단·최종 확률에 반영됩니다. 최고 평가라도 지명을 보장하지 않으며, 확정한 지원을 같은 시즌에 다시 돌릴 수 없습니다. 지명 라운드·구단·계약금·미지명 결과는 해당 시즌 이력에 남습니다.

프로는 한 시즌을 24개 평가 구간으로 나눕니다. 같은 시즌에 1군과 2군을 오갈 수 있습니다. 각 구간의 출장을 당시 소속에만 합산하며 1군과 2군이 동시에 출장한 것으로 처리하지 않습니다.

- 기본 감독 평점은 `포지션 기량 × 0.50 + 최근 경기력 × 0.32 + 신뢰 × 0.12 + 멘탈 × 0.06 + 경쟁 보정 + 주전 공백 보정 - 피로 보정`입니다. 최근 경기력은 실제 해당 구간 타격·투구 성적의 이동 평균이며 2군에서는 높은 기준으로 평가합니다.
- 2군은 두 번째 평가부터 평점 64·경기력 56 이상이면 콜업할 수 있습니다. 부상 재활과 피로 회복이 먼저 필요한 경우에는 유보합니다.
- 1군에서 두 구간 연속 부진하고 평점이 낮거나, 강한 경쟁자 복귀·누적 피로 88 이상·장기 부상이 발생하면 2군으로 조정합니다.
- 주전 부상으로 생기는 공백은 실제 평가 점수에 영향을 줍니다. 부상은 출장을 줄이고, 피로는 경기력과 출장량에 반영됩니다. 2군 휴식·회복 훈련·컨디셔닝은 피로를 줄입니다.
- 감독 평가 이력에서 24개 구간의 실제 소속, 성적, 이동 사유, 경기력·신뢰·피로·경쟁을 확인할 수 있습니다.

아마추어·1군·2군 통산은 따로 계산합니다. 학교와 2군 경력은 프로 1군 수상이나 해외 진출 경력에 포함하지 않습니다. KBO 경력은 1군 등록 145일당 1년, 한 시즌 최대 1년으로 누적합니다. 단순히 프로 구단에 오래 있었다고 해외 진출 조건을 충족하지는 않습니다.

학생·독립선수에게는 시즌 지원금 150만원이 지급되며 학생 훈련비는 낮게 책정합니다. 프로 첫 연봉은 3,000만원이며 구단은 시즌 기록·WAR·1군 등록일과 전년 연봉을 반영한 다음 연봉을 먼저 제시합니다. 시즌 종료 후 제안액 초과~2배 이하 범위에서 재협상을 한 번 요청할 수 있습니다. 성적이 좋고 추가 인상 요구율이 작을수록 수락 확률이 높으며, 거절되면 첫 제안을 유지합니다. 요청 금액·확률·결과는 저장되고 새로고침해도 재시도할 수 없습니다. KBO 첫 FA 자격은 1군 등록 경력 8시즌(4년제 대학 졸업 입단은 7시즌), FA 권리 행사 후 재취득은 다시 4시즌입니다. 145일 이상 등록 시즌은 1시즌으로, 미달 시즌의 등록일은 합산하여 145일당 1시즌으로 계산하고 초과일은 이월하지 않습니다. 국내·해외 FA 계약이나 소속팀 FA 계약을 선택할 때만 권리 행사 연도를 기록하며 일반 재계약은 자격을 소진하지 않습니다. 전체 일정·금융·드래프트·FA 규정은 게임을 위해 간소화한 것으로 실제 협회 규정의 완전한 복제는 아닙니다.

### 드래프트·대표팀·상무

드래프트는 11라운드·10개 구단 기준으로 예상 라운드, 라운드 내 순위, 전체 순위와 예상 범위를 표시합니다. 화면의 지명 확률은 실제 선발 추첨에 사용하는 확률과 같습니다. 구단 수요와 시즌 성적을 반영한 **게임 내 예상**이며 실제 KBO 드래프트 예측 서비스가 아닙니다.

진로·계약 화면에서 청소년·대학·성인 대표팀 및 상무 선발 예상 확률과 지원 가능 사유를 확인할 수 있습니다. 각 심사는 시즌당 한 번이며 결과는 커리어에 남습니다. 대표팀 선발은 이력에 기록하며 별도 국제대회 경기·메달·병역 특례는 시뮬레이션하지 않습니다.

상무는 다음 시즌 입대 나이 18~27세의 KBO 미필 선수가 지원할 수 있는 게임 모형입니다. 실제 신체검사·서류·실기 등 공고 요건은 모사하지 않습니다. 선발 후 다음 시즌부터 18개월 동안 원소속 구단 계약을 보류하고 상무 소속 2군 경기를 치릅니다. 첫 시즌 12개월, 다음 시즌 첫 6개월 뒤 원소속 구단으로 복귀하며 복무 기간은 1군 등록 경력으로 인정하지 않습니다. 복무 중 구단 연봉은 비례 중단하고 게임 내 월 150만원의 수당을 적용합니다. 대표팀·상무 선발과 구단 승인·연봉 협상 확률은 공식 공개 확률이 아닌 게임 자체 계산식입니다.

### FA·포스팅 적용 범위

| 경로                 | 자격 및 절차                              |
| -------------------- | ----------------------------------------- |
| KBO 첫 FA            | 등록 8시즌, 4년제 대학 졸업 입단은 7시즌  |
| FA 재취득            | FA 계약 시작 시즌부터 다시 등록 4시즌     |
| KBO → NPB·MLB 포스팅 | 두 리그 모두 등록 7시즌 + 소속 구단 승인  |
| FA 해외 진출         | FA 자격으로 진출, 포스팅 승인 불필요      |
| NPB → MLB            | 기존 게임 규칙인 NPB 1군 100일 이상 3시즌 |

OVR 68·78은 KBO 법적 자격 조건에서 제거했습니다. 포스팅 허가 요청은 시즌당 한 번이며 승인 전에는 해외 포스팅 계약을 제시하지 않습니다. FA·포스팅 기본 자격을 적용하며 국가대표 보상 등록일, 부상 예외, FA 보상 등 세부 특례는 현재 적용하지 않습니다. FA 계약도 현재 게임의 1년 단위 계약 흐름을 사용합니다.

공식 참고 위치는 [KBO 규정·규칙](https://www.koreabaseball.com/Reference/Etc/GameRule.aspx), [병무청](https://www.mma.go.kr/), [국군체육부대](https://www.sangmu.mil.kr/)입니다. 이번 작업에서는 환경의 네트워크 정책이 이 도메인들을 차단하여 최신 원문을 직접 대조하지 못했습니다. 현재 반영한 기본 자격과 세부 미적용 범위를 구분하며, 공식 도메인 접근 허용 후 최신 규정·공고 대조가 필요합니다.

## 저장과 복원

이 브라우저의 `localStorage`에 자동 저장합니다. 계정·클라우드 동기화는 없습니다. **커리어 히스토리 → 백업 다운로드/불러오기**로 JSON 파일을 이동할 수 있습니다. 하단의 **백업** 버튼도 사용할 수 있습니다.

**커리어 보관함**은 세 개의 저장 슬롯을 제공합니다. 현재 선수를 슬롯에 저장하면 이후 진행도 해당 슬롯에 자동 저장됩니다. 다른 슬롯을 불러오거나 새 커리어를 시작해도 이전 슬롯은 보존됩니다. 기존 단일 저장 파일은 그대로 읽으며, 보관함에서 원하는 슬롯에 저장하면 됩니다.

새 커리어 시작·파일 불러오기·슬롯 전환·자동 백업 복원 전에 현재 커리어를 자동 백업합니다. 슬롯을 덮어쓸 때는 그 슬롯의 이전 내용도 보호하며, 최근 두 개의 서로 다른 백업을 유지합니다. 자동 백업에 실패하면 현재 커리어 교체를 중단합니다. 보관함에서 백업을 복원하거나 파일로 내려받을 수 있으며, 손상된 원본은 복원 대신 파일 다운로드로 보존합니다. 브라우저 데이터 삭제와 기기 이동에 대비한 장기 보관에는 파일 백업을 사용하세요.

저장 형식은 v2입니다. 기존 v1 프로 커리어를 불러오면 나이·이름·기존 성적·자산·계약을 보존한 채 프로 경력으로 변환합니다. 과거 고교·대학 이력을 만들어 넣거나 선수를 16세로 되돌리지 않습니다. 기존 시즌에 없던 2군 기록과 감독 평가는 업데이트 이후부터 기록합니다. 고교부터 시작하려면 백업 후 새 커리어를 만드세요.

잘못되거나 지원하지 않는 저장 파일은 거부합니다. 기존 저장이 손상된 경우 원본을 자동으로 덮어쓰지 않습니다. 브라우저 저장 공간이 부족하면 자동 저장 오류를 표시하므로 파일 백업을 사용하세요.

## 현재 범위와 확장

‘이번 생은 야구다’에서 사용자가 설명한 **시즌 단위 진행과 상세 기록**을 핵심으로 구현한 독자적인 초기 버전입니다. 참고 사이트의 접근이 네트워크 정책으로 차단되어 원작의 화면·수치·밸런스를 직접 검증하거나 그대로 재현한 상태는 아닙니다. 구단 구성·선수·일정은 시뮬레이션용이며 실제 로스터를 반영하지 않습니다.

WAR·wRC+·FIP는 게임 내 간이 지표입니다. 구단 순위는 매일의 가상 경기 승패로 계산하고, 개인 기록은 별도 확률 모형으로 생성합니다. 개인 리더보드는 구단별 타자 4명·투수 2명의 대표 표본이며 전체 로스터가 아닙니다. NPB·MLB의 디비전은 통합 순위로 표시합니다.

투타겸업, 포스트시즌, 실제 구단 로스터, 복수 연도 계약, 실제 FA 보상, 방출, 일반 현역 입대·국제대회 메달 병역 특례, 구종별 육성, 에이전트·스폰서·생활 이벤트는 아직 구현하지 않았습니다. 세부 수치와 밸런스는 향후 원작 규칙 확인과 플레이 결과를 바탕으로 조정할 대상입니다.

## 클라우드 환경 재사용

기존 `/workspace/road-to-legend` 체크아웃을 그대로 사용합니다. 각 클라우드 작업은 이미 격리되어 있으므로 별도 Git worktree를 만들 필요가 없습니다.

설치에는 `registry.npmjs.org` 접근만 필요합니다. 실행 중 외부 서비스나 비밀 값은 필요하지 않습니다. `node_modules`·빌드 파일은 유지될 수 있지만, 실행 중인 개발 서버는 새 작업에서도 유지된다고 가정하지 말고 위 실행 명령으로 다시 시작하세요.
