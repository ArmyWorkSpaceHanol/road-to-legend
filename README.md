# ROAD TO LEGEND

혼자 즐기는 야구 선수 인생 웹게임. **육성 계획 선택 → 버튼 한 번으로 한 시즌 진행 → 상세 기록·시상식 확인 → 계약 선택**을 반복하며 커리어를 쌓습니다.

React + TypeScript + Vite로 구현한 브라우저 게임입니다. 서버·데이터베이스·API 키가 필요하지 않습니다. 한국어 폰트도 함께 제공하므로 실행 중 외부 폰트 서비스에 의존하지 않습니다.

## 실행

Node.js 24 이상을 사용합니다. 검증한 버전은 `.nvmrc`의 24.22.1입니다.

```sh
cd /workspace/road-to-legend
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

일반 PC에서는 원하는 작업 디렉터리와 쓰기 가능한 npm 캐시를 사용하면 됩니다. 개발 서버는 5173번 포트에서 실행됩니다.

```sh
npm test                       # 시뮬레이션·기록·계약·저장 데이터 테스트
npm run build                  # 타입 검사 및 프로덕션 빌드
npm run preview -- --port 4173  # 빌드 결과 실행
```

브라우저 통합 검증은 개발 서버를 실행한 상태에서 별도 터미널로 진행합니다.

```sh
CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
```

Chromium이 없는 PC에서는 `npx playwright install chromium`을 실행한 뒤 `npm run test:browser`를 사용합니다. `BASE_URL`로 검사할 서버를 지정할 수 있습니다. 캡처는 Git에서 제외된 `test-results/`에 저장합니다.

## GitHub Pages에서 플레이

`main` 푸시 시 GitHub Actions가 테스트·빌드를 실행하고 GitHub Pages로 배포합니다. 첫 배포 전에는 저장소의 [Settings → Pages](https://github.com/ArmyWorkSpaceHanol/road-to-legend/settings/pages)에서 **Build and deployment → Source → GitHub Actions**를 선택해야 합니다. API 키나 별도 서버는 필요하지 않습니다.

설정을 완료한 뒤 [Actions](https://github.com/ArmyWorkSpaceHanol/road-to-legend/actions/workflows/deploy.yml)에서 **Validate and deploy to GitHub Pages** 워크플로를 실행하거나 실패한 실행을 다시 실행하세요. 배포가 성공하면 다음 주소에서 플레이할 수 있습니다.

<https://armyworkspacehanol.github.io/road-to-legend/>

Vite 빌드의 리소스 경로는 상대 경로이므로 저장소 하위 경로에서도 카드 화면과 폰트가 정상 로드됩니다. 개발 환경과 배포 사이트의 저장 데이터는 서로 별개이므로 기존 커리어를 옮기려면 백업 파일을 불러오세요.

## 플레이

- 처음 접속하거나 **새 커리어**를 누르면 이름, 타자·투수, 포지션, 선호 팀(데뷔 구단)을 설정합니다.
- 기본 설정 다음에는 뒷면으로 놓인 **시작 카드 3장**이 나옵니다. 한 장씩 뒤집어 모두 확인한 뒤, 마음에 드는 카드 하나를 선택하고 시작합니다. 카드를 선택하기 전까지 기존 커리어는 교체되지 않습니다.
- 타자는 **거포형·수비형·주루형·균등형**, 투수는 **강속구형·제구형·변화구형·균등형** 중 서로 다른 컨셉 3장이 무작위로 나옵니다. 세부 능력치는 컨셉에 맞는 기준값에서 각각 ±5로 변동하며, 표시된 값이 그대로 시작 능력치가 됩니다. 기본 설정으로 돌아갔다 와도 같은 선수 유형의 카드와 공개 상태가 유지됩니다.
- 선택한 컨셉과 최초 능력치는 저장·복원되고 이후 육성은 자유롭습니다. 이전 버전의 저장 파일도 그대로 사용할 수 있습니다.
- **선수 육성**에서 육성 방향 1개, 훈련 지원 1개를 선택합니다. 시즌을 진행할 때 성장·비용이 한 번 적용됩니다.
- **시즌 진행** 한 번에 해당 리그의 정규시즌 전체를 시뮬레이션합니다. KBO 144경기, NPB 143경기, MLB 162경기입니다.
- **나의 기록실**에서 원시 기록과 비율 기록, 연도별·통산 성적을 확인합니다. 통산 비율은 합산한 타수·안타 등으로 다시 계산합니다.
- **리그 순위**는 구단 순위와 가상 대표 선수들의 개인 순위를 제공합니다. 열 이름으로 정렬하고 규정 출장 선수만 볼 수 있습니다.
- **시상식**에서 시즌 MVP, 타격왕, 홈런왕, 타점왕, 도루왕, 최우수 투수, ERA·삼진 타이틀, 해당 포지션 골든글러브를 확인합니다. 첫 시즌 WAR 1.5 이상이면 게임 내 신인왕도 받습니다.
- 시즌 종료 후 **계약·해외 진출**에서 제안 하나를 고릅니다. **다음 시즌 준비**를 누르면 선택한 계약이 적용되며, 기본 선택은 재계약입니다.
- 19세에 데뷔해 40세 시즌 후 은퇴합니다. 커리어 기록과 트로피는 계속 열람할 수 있습니다.

### 육성과 경기 결과

타자는 컨택·파워·스피드·수비·선구안·멘탈을, 투수는 제구·구위·체력·변화구·위기 관리·멘탈을 육성합니다. 능력치 상한은 99이며 성장률은 나이에 따라 달라집니다. 32세부터 노화가 적용됩니다. 회복 훈련·컨디셔닝 지원은 부상 확률을 줄이고, 부상은 실제 출장 수를 줄입니다.

컨택·선구안은 출루와 삼진, 파워는 장타, 스피드는 주루, 수비는 기여도, 멘탈은 득점 생산에 영향을 줍니다. 투수의 제구·구위·변화구는 상대 타석 결과에, 체력은 소화 이닝에, 위기 관리·멘탈은 실점에 영향을 줍니다. 동일한 저장 상태는 동일한 결과를 내는 시드 기반 시뮬레이션입니다.

### 해외 진출 규칙

| 경로             | 조건                            |
| ---------------- | ------------------------------- |
| KBO → NPB        | KBO 5시즌 완료 + OVR 68 이상    |
| KBO → MLB 포스팅 | KBO 7시즌 완료 + OVR 78 이상    |
| NPB → MLB        | 해외 3시즌 완료 + OVR 78 이상   |
| 해외 → KBO 복귀  | 해외에서 시즌 종료 후 복귀 제안 |

실제 리그의 복잡한 등록·포스팅·FA 규정 대신, 이 초기 버전의 명시적인 게임 규칙을 사용합니다. 이적한 리그의 난이도가 타격·투구 성적에 반영됩니다.

## 저장과 복원

이 브라우저의 `localStorage`에 자동 저장합니다. 계정·클라우드 동기화는 없습니다. **커리어 히스토리 → 백업 다운로드/불러오기**로 JSON 파일을 이동할 수 있습니다. 하단의 **백업** 버튼도 사용할 수 있습니다. 새 커리어는 기존 커리어를 교체하므로 먼저 백업하세요.

잘못되거나 지원하지 않는 저장 파일은 거부합니다. 기존 저장이 손상된 경우 원본을 자동으로 덮어쓰지 않습니다. 브라우저 저장 공간이 부족하면 자동 저장 오류를 표시하므로 파일 백업을 사용하세요.

## 현재 범위와 확장

‘이번 생은 야구다’에서 사용자가 설명한 **시즌 단위 진행과 상세 기록**을 핵심으로 구현한 독자적인 초기 버전입니다. 참고 사이트의 접근이 네트워크 정책으로 차단되어 원작의 화면·수치·밸런스를 직접 검증하거나 그대로 재현한 상태는 아닙니다. 구단 구성·선수·일정은 시뮬레이션용이며 실제 로스터를 반영하지 않습니다.

WAR·wRC+·FIP는 게임 내 간이 지표입니다. 구단 순위는 매일의 가상 경기 승패로 계산하고, 개인 기록은 별도 확률 모형으로 생성합니다. 개인 리더보드는 구단별 타자 4명·투수 2명의 대표 표본이며 전체 로스터가 아닙니다. NPB·MLB의 디비전은 통합 순위로 표시합니다.

투타겸업, 포스트시즌, 드래프트, 실제 구단 로스터, 복수 연도 계약, FA 보상, 구종별 육성, 에이전트·스폰서·생활 이벤트는 아직 구현하지 않았습니다. 세부 수치와 밸런스는 향후 원작 규칙 확인과 플레이 결과를 바탕으로 조정할 대상입니다.

주요 파일:

- `src/game.ts`: 순수 시뮬레이션, 지표 계산, 성장·부상, 계약·해외 진출, 저장 검증
- `src/App.tsx`: 한국어 인터페이스, 로컬 저장, 백업·복원
- `src/styles.css`: 데스크톱·모바일 레이아웃
- `src/game.test.ts`: 엔진과 커리어 생명주기 테스트
- `scripts/smoke.mjs`: 실제 Chromium 플레이·저장·모바일 화면 통합 검증

## 클라우드 환경 재사용

기존 `/workspace/road-to-legend` 체크아웃을 그대로 사용합니다. 각 클라우드 작업은 이미 격리되어 있으므로 별도 Git worktree를 만들 필요가 없습니다.

설치에는 `registry.npmjs.org` 접근만 필요합니다. 실행 중 외부 서비스나 비밀 값은 필요하지 않습니다. `node_modules`·빌드 파일은 유지될 수 있지만, 실행 중인 개발 서버는 새 작업에서도 유지된다고 가정하지 말고 위 실행 명령으로 다시 시작하세요.
